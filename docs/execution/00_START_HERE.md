## What this project is (1 paragraph)
`agent-arena` is a TCP substrate that runs turn-based multi-agent "debate" matches. A
**referee** process hosts a match; two **player** processes connect, register, get a role
(`PRO`/`CON`), and exchange moves until `GAME_OVER`. Moves are generated by an LLM
(**Google Gemini**, via the `google-genai` SDK — *not* Anthropic). Code lives in
`src/agent_arena/`. Tests in `tests/`. You run things with **`uv`**. OS is **Windows +
PowerShell**.
